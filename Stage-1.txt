1.1  PEPTIDE BUILD

  ▸ Submit GRKKRRQRRRPQ to the PEP-FOLD server.
  ▸ PEP-FOLD returns several predicted models; keep the best 1-3
    (or 1-5).
  ▸ Proceed with the Top-1 model first and save it as TAT.pdb

1.2  SYSTEM PREPARATION AND MD RUN (GROMACS)

  ◆ Clean the PDB
     grep -v HOH TAT.pdb > TAT_clean.pdb

  ◆ Topology
     gmx pdb2gmx -f TAT_clean.pdb -o TAT_processed.gro -ff charmm36-feb2026_cgenff-5.0 -water tip3p

  ◆ Box
     gmx editconf -f TAT_processed.gro -o TAT_box.gro -c -d 1.5 -bt cubic

  ◆ Solvate
     gmx solvate -cp TAT_box.gro -cs spc216.gro -o TAT_solv.gro -p topol.top


  ◆ Add ions     
	 gmx grompp -f ions.mdp -c TAT_solv.gro -p topol.top -o ions.tpr 
	 gmx genion -s ions.tpr -o TAT_solv_ions.gro -p topol.top -pname NA -nname CL -neutral -conc 0.15
       → select group: SOL


  ◆ Energy minimization
     gmx grompp -f minim.mdp -c TAT_solv_ions.gro -p topol.top -o em.tpr
     gmx mdrun -v -deffnm em
     gmx energy -f em.edr -o potential.xvg


  ◆ NVT equilibration
     gmx grompp -f nvt.mdp -c em.gro -r em.gro -p topol.top -o nvt.tpr
     gmx mdrun -deffnm nvt -v
     gmx energy -f nvt.edr -o temperature.xvg


  ◆ NPT equilibration
     gmx grompp -f npt.mdp -c nvt.gro -r nvt.gro -t nvt.cpt -p topol.top -o npt.tpr
     gmx mdrun -deffnm npt -v
     gmx energy -f npt.edr -o pressure.xvg
     gmx energy -f npt.edr -o density.xvg


  ◆ Production MD
     gmx grompp -f md.mdp -c npt.gro -t npt.cpt -p topol.top -o MDrun1.tpr
     gmx mdrun -deffnm MDrun1 -v


───────────────────────────────────────────────────────────────────
───────────────────────Re-run──────────────────────────────────────

  ◆ CONTINUE AN INTERRUPTED RUN (resume from checkpoint)
     gmx mdrun -deffnm MDrun1 -cpi MDrun1.cpt -append -v
	 
  
  ◆ EXTEND A FINISHED RUN (example: +100 ns)

     gmx convert-tpr -s MDrun1.tpr -extend 100000 -o MDrun1_ext.tpr
     gmx mdrun -deffnm MDrun1 -s MDrun1_ext.tpr -cpi MDrun1.cpt -append -v
 
     NOTE: -extend is in ps (100000 ps = 100 ns).


───────────────────────────────────────────────────────────────────
───────────────────────Centering───────────────────────────────────

  ◆ QUICK CENTERING (peptide in water)
     gmx trjconv -s MDrun1.tpr -f MDrun1.xtc -o MDrun1_centered.xtc -pbc mol -center -ur compact
        → center group: Protein
        → output group: System
		
		
  ◆ STEP-BY-STEP CENTERING (more robust)

   #Step-a: Make molecules whole
     gmx trjconv -s MDrun1.tpr -f MDrun1.xtc -o MDrun1_whole.xtc -pbc whole
       → output group: System
 
   #Step-b: Remove jumps across the box
     gmx trjconv -s MDrun1.tpr -f MDrun1_whole.xtc -o MDrun1_nojump.xtc -pbc nojump
       → output group: System
 
   #Step-c: Center on the peptide
     gmx trjconv -s MDrun1.tpr -f MDrun1_nojump.xtc -o MDrun1_whole_pbc.xtc -pbc mol -center -ur compact
       → center group: Protein
       → output group: Syste
	   
───────────────────────────────────────────────────────────────────	   
───────────────────ROTATION AND TRANSLATION────────────────────────

  ◆ REMOVE ROTATION AND TRANSLATION (fit to the first frame)
 
     gmx trjconv -s MDrun1.tpr -f MDrun1_whole_pbc.xtc -o MDrun1_fit.xtc -fit rot+trans
       → fit group:     Backbone
       → output group:  Protein (or System)
 
        NOTE: run the fit as a separate step after centering.
        Do not combine -fit with -pbc in the same command.

1.3  PEPTIDE MD ANALYSIS


                        ───────────────ANALYSIS  →  TRAJECTORY─────────────────────────────
 
                         Analysis               Recommended trajectory
                        ─────────────────────  ───────────────────────
                        RMSD                   MDrun1_whole_pbc.xtc
                        RMSF                   MDrun1_whole_pbc.xtc
                        Radius of gyration     MDrun1_whole_pbc.xtc
                        PCA / FEL              MDrun1_whole_pbc.xtc
                        DSSP                   MDrun1_whole_pbc.xtc
                        H-bond                 MDrun1_whole_pbc.xtc
                        Visualization          MDrun1_centered.xtc
                        Diffusion analysis     MDrun1_nojump.xtc
                        ───────────────────────────────────────────────────────────────────	
	
  ◆ Index file
     gmx make_ndx -f MDrun1.tpr -o index.ndx

  ◆ RMSD
     gmx rms -s MDrun1.tpr -f MDrun1_whole_pbc.xtc -n index.ndx -o TAT_RMSD.xvg -tu ns
       → least squares fit group: Backbone
       → RMSD calculation group: Backbone

  ◆ RMSF
     gmx rmsf -s MDrun1.tpr -f MDrun1_whole_pbc.xtc -o TAT_RMSF.xvg -res
       → group: Backbone

  ◆ Radius of gyration
     gmx gyrate -s MDrun1.tpr -f MDrun1_whole_pbc.xtc -o TAT_Rg.xvg
       → select: Protein

  ◆ Hydrogen bonds
     gmx hbond -s MDrun1.tpr -f MDrun1_whole_pbc.xtc -n index.ndx -cutoff 0.35 -hbr 0.35 -hba 30 -num hbnum.xvg -dist hbdist.xvg -ang hbang.xvg -tu ns
       → run twice: Protein - Protein  (intra-peptide)
                    Protein - Water    (peptide-water)

  ◆ Secondary structure (DSSP)
    gmx dssp -s MDrun1.tpr -f MDrun1_whole_pbc.xtc -sel "Protein" -hmode dssp -o TAT_ss.dat -num TAT_ss_num.xvg -tu ns


───────────────────────────────────────────────────────────────────
─────────────────────────FEL───────────────────────────────────────

  ◆ PCA-based FEL

     #Step-a: Covariance
       gmx covar -s MDrun1.tpr -f MDrun1_whole_pbc.xtc -n index.ndx -o eigenval.xvg -v eigenvec.trr -av average.pdb
        → least squares fit group: Backbone
        → covariance group: Backbone

     #Step-b: PC1 projection
       gmx anaeig -s MDrun1.tpr -f MDrun1_whole_pbc.xtc -v eigenvec.trr -first 1 -last 1 -proj pc1.xvg -tu ns
        → fit group (same as covar): Backbone
        → group of 36 elements matching eigenvectors: Backbone

     #Step-c: PC2 projection
       gmx anaeig -s MDrun1.tpr -f MDrun1_whole_pbc.xtc -v eigenvec.trr -first 2 -last 2 -proj pc2.xvg -tu ns
        → fit group (same as covar): Backbone
        → group of 36 elements matching eigenvectors: Backbone

     #Step-d: Combine PC1 and PC2 in gromacs (or use python)
        paste <(awk '!/^[@#]/ {print $2}' pc1.xvg) <(awk '!/^[@#]/ {print $2}' pc2.xvg) > pc1_pc2.xvg
        gmx sham -f pc1_pc2.xvg -ls FEL.xpm -notime -tsham 310.15 -nlevels 100
    
	NOTE: RMSD-RG based FEL
───────────────────────────────────────────────────────────────────
────────────────────Clustering─────────────────────────────────────    

  gmx cluster -s MDrun1.tpr -f MDrun1_whole_pbc.xtc -n index.ndx -method gromos -cutoff 0.15 -o clusters.xpm -g cluster.log -cl cluster_centers.pdb -sz cluster_size.xvg -dist cluster_rmsd.xvg -tu ns
   → Least squares fit: Backbone
   → RMSD calculation: Backbone
